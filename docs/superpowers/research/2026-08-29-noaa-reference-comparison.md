# NOAA / Reference-Site Comparison for Remaining CoastalNow Locations

This note records the rollout rule used for locations without an exact current NOAA tide-prediction station.

## Decision rule

1. Prefer an exact/local current NOAA tide-prediction station.
2. If NOAA has no current local prediction station, compare established reference sites and local official guidance.
3. CoastalNow remains NOAA-only; it will not imitate proprietary satellite/model tide calculations.
4. A nearby/regional NOAA station may be used only when there is a defensible geographic/reference precedent, and the page must disclose that the prediction is based on a nearby NOAA station and local timing/height may differ.
5. If neither an exact station nor a defensible nearby NOAA reference exists, keep the page Preview.

## Confirmed examples

- Emerald Isle, NC: use exact official NOAA subordinate station `TEC2837` Bogue Inlet. No fallback is needed.
- Seaside, OR: local Seaside visitor guidance uses NOAA North Jetty, WA `9440574`, referenced to Astoria, and explicitly warns that local tides can vary from predictions.
- Cannon Beach, OR: local Cannon Beach guidance likewise identifies North Jetty, WA as the closest NOAA station used for Cannon Beach predictions.
- Huntington Beach, CA: reference services use Newport Bay Entrance when NOAA-local coverage is unavailable, with an estimated/nearby-station disclosure.
- Malibu, CA: reference services use Santa Monica as a nearby NOAA basis and disclose approximation.
- Oceanside, CA: the historical Oceanside NOAA station has no current predictions; reference services use La Jolla as a nearby NOAA basis with disclosure.
- Laguna Beach, CA: reference services use Newport Bay Entrance with disclosure.
- Kill Devil Hills, NC: NOAA-based reference services use Kitty Hawk (ocean) as the nearest tide station and disclose distance/source.
- Corolla, NC: reference sites use Currituck Beach Light as the closest tide station; a current NOAA identifier still needs to be confirmed before promotion.
- Topsail Beach, NC: historical NOAA `TEC2841` New Topsail Inlet was removed in 2017; do not promote until a current defensible NOAA basis is confirmed.

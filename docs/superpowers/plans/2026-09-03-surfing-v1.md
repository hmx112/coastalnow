# CoastalNow Surfing v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a 10-location Surfing pilot with a 0–100 Surf Conditions Score, conservative Safety Gate, Surfing hub/location pages, bidirectional Tide/Fishing/Surfing navigation, and reuse of the existing Activity refresh pipeline.

**Architecture:** Reuse the existing shared Condition Snapshot and Activity generator. Add a location-aware Activity Registry helper, a Surfing-specific scorer and renderer, then extend the existing build/SEO/navigation dispatchers without adding a new data workflow or provider. Surfing remains limited to a validated allowlist while Fishing continues on all locations.

**Tech Stack:** Python 3.12, stdlib unittest, existing NOAA/NOS/CO-OPS + NOAA NWS collectors, static HTML generation, GitHub Actions, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-09-03-surfing-v1-design.md`

## Global Constraints

- Existing Tide and Fishing URLs must not change.
- No paid surf API and no new external provider in v1.
- Surf Conditions Score is a normalized 0–100 planning metric, not a measured ocean value, safety score, break-specific forecast, skill recommendation, or guarantee.
- v1 score weights are fixed: wave height 30%, wave period 25%, wind 25%, weather 10%, daylight/time of day 10%.
- Tide is contextual and is not included in the v1 Surf Conditions Score.
- Safety Gate always overrides quality score.
- Alert lookup failure is unknown, never equivalent to no alerts.
- Missing wave height or wave period => Limited and suppress headline numeric score.
- Missing wind/core forecast => Unavailable.
- NOT RECOMMENDED priority remains above Limited.
- Only pilot Surfing locations are generated, linked, indexed, and listed in sitemap/hub.
- No NOAA/NWS logos.
- No Pinterest Surfing RSS in v1.
- Existing 3-hour Activity refresh, 1-hour safety-alert refresh, and shared `coastalnow-site-writes` concurrency are reused.

```python
def activity_enabled_for_location(activity: dict, location_slug: str) -> bool:
    if not activity.get("enabled"):
        return False
    allowlist = activity.get("location_allowlist")
    return allowlist is None or location_slug in allowlist


def enabled_activities_for_location(location: dict, registry: dict | None = None) -> list[dict]:
    source = ACTIVITIES if registry is None else registry
    return [
        dict(item)
        for item in source.values()
        if activity_enabled_for_location(item, location["slug"])
    ]
```
